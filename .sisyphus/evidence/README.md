# Evidence Notes

Direktori ini menyimpan bukti verifikasi selama development prototype.

## Pola Nama

Gunakan pola:

```text
task-{N}-{scenario}.ext
```

Contoh:

```text
task-16-identity-validation.png
task-18-keyboard.txt
task-19-run-docs.txt
```

Untuk verifikasi final lintas task, gunakan subdirektori seperti:

```text
final-qa/
```

## Isi Evidence

Evidence dapat berupa:

- log build atau command output (`.txt`);
- snapshot browser/accessibility (`.md` atau `.yml`);
- screenshot browser (`.png`);
- catatan manual QA ringkas (`.txt`).

Evidence adalah catatan proses development, bukan bagian dari data resmi Universitas Terbuka.
